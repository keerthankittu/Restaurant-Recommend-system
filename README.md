-Designed a user-friendly web application to solve customer decision fatigue by recommending dining options.
 Focused on improving user experience (UX) and simplifying search for 9,500+ restaurants   
-It utilizes a Content-Based Filtering approach with TF-IDF Vectorization and Cosine Similarity to analyze metadata for 9,500+ restaurants (cuisines and names) and recommend the top-N most similar dining options. 
-Features include real-time search with fuzzy matching to handle user typos.
